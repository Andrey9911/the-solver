The Solver - Telegram Bot Ecosystem
The Solver - это многофункциональный телеграм-бот, разработанный как единая экосистема для доступа к цифровым товарам, инструментам блокчейна TON и возможностям искусственного интеллекта. Проект объединяет в себе автоматизированный маркетплейс, аналитические инструменты и умного ассистента поддержки.

🚀 Основной функционал
Проект разделен на три логических модуля, которые взаимодействуют друг с другом:

1. Цифровой Маркетплейс Бот предоставляет удобный интерфейс для покупки подписок и аккаунтов (Gemini, OpenAI, Claude и др.).

Архитектура магазина построена на базе JSON-файлов, что обеспечивает быстрое добавление новых категорий.

Реализована проверка баланса пользователя, автоматическая выдача товара файлом и сохранение истории покупок.

Все товары адаптированы для использования в регионах с ограничениями (работа без VPN).

2. Интеграция с TON (The Open Network) Бот выступает проводником в мир Web3, используя API (TonAPI) и библиотеки для работы с блокчейном.

Аналитика: Просмотр топ-5 холдеров конкретного жетона (Jetton) с расчетом процентного соотношения владения.

Кошелек: Возможность подключения TON-кошелька для отслеживания баланса и адреса.

Голосование: Встроенная система опросов для сообщества (DAO-элементы).

3. AI-Core и RAG (Умная поддержка) В бота встроен интеллектуальный собеседник, работающий на базе LLM.

RAG (Retrieval-Augmented Generation): Ассистент использует векторную базу знаний для ответов на вопросы о сервисе, тарифах и технических проблемах, минимизируя галлюцинации.

Генерация контента: Интеграция с n8n позволяет генерировать тексты и видео по запросу пользователя через внешние нейросети (Sora/Video generation).

Поддержка: Умная маршрутизация запросов пользователей.

🛠 Технический стек
Проект реализован на Node.js с использованием современной модульной архитектуры.

Фреймворк: grammY - для взаимодействия с Bot API.

MTProto: Библиотека GramJS (telegram) - для реализации функций UserBot и работы с клиентом Telegram напрямую (получение обновлений, парсинг чатов).

База данных: Файловая система (JSON) для товаров и session для хранения состояний пользователей.

Векторный поиск: Интеграция с векторными базами данных для RAG-системы.

Automation: n8n (hosted on Amvera) - для оркестрации сложных AI-сценариев и вебхуков.

📥 Как пользоваться
Чтобы начать работу с ботом, выполните следующие шаги:

Откройте Telegram.

Введите в поиске юзернейм бота: YOUR_BOT_USERNAME (замените на реальный юзернейм) или перейдите по прямой ссылке.

Нажмите кнопку Start (или отправьте команду /start).

В главном меню выберите интересующий раздел:

МаркетПлейс - для покупки подписок.

AI - для общения с нейросетью или генерации контента.

TON Обозреватель - для аналитики кошельков и токенов.

👨‍💻 Разработка и вклад
Проект находится в активной стадии разработки. Планируется внедрение полноценной базы данных (MongoDB/PostgreSQL) вместо JSON, расширение списка поддерживаемых нейросетей через OpenRouter и улучшение аналитики TON.
